# Summarize Sector Titles

Creates summary statistics for title data grouped by sector.

## Usage

``` r
summarize_sector_titles(df, has_features = FALSE, has_similarity = FALSE)
```

## Arguments

- df:

  Data frame with title data

- has_features:

  Whether derived features are present

- has_similarity:

  Whether similarity was computed

## Value

Tibble with sector summary statistics
