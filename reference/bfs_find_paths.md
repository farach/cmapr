# BFS to find all paths between two nodes

BFS to find all paths between two nodes

## Usage

``` r
bfs_find_paths(adj_list, start, end, max_depth)
```

## Arguments

- adj_list:

  Adjacency list

- start:

  Start node

- end:

  End node

- max_depth:

  Maximum path length

## Value

List of paths (each path is a character vector)
